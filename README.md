# VKinder

VKinder — чат-бот ВКонтакте для поиска людей с целью знакомства.

Бот собирает информацию о пользователе, выполняет поиск подходящих анкет и отправляет их в диалог с фотографиями профиля.

## Возможности

- Сбор возраста, пола и города пользователя.
- Поиск пользователей ВКонтакте по заданным параметрам.
- Получение фотографий профиля кандидатов.
- Сортировка фотографий по количеству лайков.
- Отправка анкет с фотографиями.
- Переключение на следующую анкету.
- Добавление анкет в избранное.
- Просмотр избранных анкет.
- Сохранение просмотренных анкет, чтобы не показывать их повторно.
- Хранение данных в PostgreSQL.

## Используемые технологии

- Python
- VK API (`vk_api`)
- PostgreSQL
- `psycopg2-binary`
- VK Bot Long Poll
- `python-dotenv`

## Структура проекта

- `main.py` — основная логика бота и обработка сообщений.
- `vkapi.py` — работа с VK API, поиск пользователей и получение фотографий.
- `database.py` — работа с базой данных PostgreSQL.
- `create_tables.sql` — SQL-запросы для создания таблиц.
- `requirements.txt` — список зависимостей.
- `.env.example` — пример файла с переменными окружения.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd <название-папки-проекта>
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация виртуального окружения:

Windows:

```bash
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка ВКонтакте

Для работы бота необходимо:

- Создать сообщество ВКонтакте.
- Включить сообщения сообщества.
- Включить Long Poll API.
- Получить токен сообщества.
- Получить пользовательский токен с необходимыми правами доступа.

Токены необходимо указать в файле `.env`:

- `GROUP_TOKEN` — токен сообщества.
- `USER_TOKEN` — пользовательский токен.

### 5. Настройка базы данных

Установить PostgreSQL и создать базу данных с названием `vkinder`.

Параметры подключения к базе данных указываются в файле `.env`:

- `DB_PASSWORD` — пароль пользователя PostgreSQL.

Выполнить SQL-запросы из файла `create_tables.sql`, чтобы создать необходимые таблицы.

### 6. Настройка переменных окружения

Скопировать файл `.env.example` в `.env` и заполнить его необходимыми значениями.

Файл `.env` не должен попадать в репозиторий.

### 7. Запуск бота

```bash
python main.py
```

## Команды бота

После завершения регистрации бот начинает показывать анкеты.

- `-` — показать следующую анкету.
- `+` — добавить текущую анкету в избранное.
- `*` — показать список избранных анкет.

## База данных

В проекте используются три таблицы:

- `users` — информация о пользователях бота.
- `favorites` — избранные анкеты.
- `viewed` — просмотренные анкеты.
